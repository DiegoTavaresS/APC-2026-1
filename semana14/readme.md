Nesta atividade desenvolvi um analisador simples de dados do SAEB utilizando Python. Aprendi a ordenar informações com algoritmos de ordenação, calcular médias e gerar rankings a partir de dados armazenados em listas e dicionários.

Utilizei o VS Code para implementar o programa e o Python Tutor para acompanhar a execução dos algoritmos. Essa atividade permitiu aplicar vários conceitos estudados durante o semestre, como estruturas de repetição, listas, dicionários e análise de dados.
