Este simulador foi desenvolvido no octoStudio para demonstrar os conceitos fundamentais de computação: entrada, processamento e saída.

O sistema aguarda uma interação do usuário (Evento).
Solicita uma interação de comando (Entrada de Dados).
Avalia se a ação foi executada (Estrutura Condicional).
Realiza a ação física no sprite (Sequência de Passos).
Exibe uma mensagem confirmando a execução (Saída de Dados).
este projeto exemplifica a programação antes da sintaxe
