Nessa semana desenvolvi um simulador no OctoStudio utilizando um robô para representar a execução de um algoritmo. O projeto foi criado com uma sequência de comandos que fazem o robô se movimentar, girar, reproduzir um som e exibir mensagens na tela.

Com essa atividade aprendi que um algoritmo é um conjunto de instruções organizadas que devem ser executadas em uma ordem específica para atingir um objetivo. Também tive meu primeiro contato com programação visual, o que facilitou a compreensão dos conceitos básicos de lógica e pensamento computacional.
