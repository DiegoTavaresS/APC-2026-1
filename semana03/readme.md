# Semana 03 – Calculadora no OctoStudio

Nesta semana eu desenvolvi uma calculadora simples utilizando o OctoStudio.

Durante a atividade aprendi a criar e utilizar variáveis para armazenar valores, além de realizar operações matemáticas básicas como soma, subtração, multiplicação e divisão.

Utilizei as variáveis `a` e `b` para representar os números da calculadora e criei outras variáveis para armazenar os resultados das operações.

A atividade me ajudou a compreender melhor como os computadores processam informações e executam cálculos a partir de instruções programadas.

Também percebi a importância da organização dos blocos e da sequência correta dos comandos para que o programa funcione adequadamente.
