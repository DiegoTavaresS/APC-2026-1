# Calculadora Interativa – OctoStudio

## Disciplina

Algoritmos e Programação de Computadores (APC)

## Autor

Diego Silva

## Objetivo

Desenvolver uma calculadora simples no OctoStudio capaz de realizar operações matemáticas básicas utilizando variáveis e operadores aritméticos.

## Conceitos Trabalhados

* Variáveis
* Operadores matemáticos
* Entrada e processamento de dados
* Lógica de programação
* Saída de informações

## Funcionamento

O programa utiliza duas variáveis:

* `a = 2`
* `b = 3`

A partir desses valores, o OctoStudio calcula automaticamente:

* Soma (`a + b`)
* Subtração (`b - a`)
* Multiplicação (`a × b`)
* Divisão (`b ÷ a`)

Os resultados são exibidos diretamente na tela por meio de variáveis visíveis.

## Algoritmo

```text
INÍCIO

a ← 2
b ← 3

soma ← a + b
subtracao ← b - a
multiplicacao ← a * b
divisao ← b / a

Mostrar soma
Mostrar subtracao
Mostrar multiplicacao
Mostrar divisao

FIM
```

## Resultado Obtido

| Operação      | Resultado |
| ------------- | --------- |
| Soma          | 5         |
| Subtração     | 1         |
| Multiplicação | 6         |
| Divisão       | 1,50      |
