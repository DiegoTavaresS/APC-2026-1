Nesta atividade desenvolvi minha primeira calculadora em Python utilizando o VS Code. Aprendi a criar funções para organizar o código, receber dados do usuário com `input()` e utilizar estruturas condicionais para escolher a operação matemática desejada.

Também utilizei o Python Tutor para acompanhar a execução do programa passo a passo e entender melhor como as variáveis são armazenadas e modificadas durante a execução. Essa atividade me ajudou a compreender melhor a lógica de programação e a importância da organização do código.
