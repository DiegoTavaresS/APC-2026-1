Nesta atividade criei um pequeno banco de dados utilizando listas e dicionários em Python. Aprendi como armazenar informações de escolas, percorrer registros com estruturas de repetição e realizar buscas simples em uma coleção de dados.

Utilizei o VS Code para desenvolver o programa e o Python Tutor para visualizar como os dados ficam organizados na memória. A atividade me ajudou a entender melhor como os programas podem armazenar e consultar informações de forma estruturada.
