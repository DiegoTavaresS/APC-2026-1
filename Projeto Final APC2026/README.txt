# Sistema de Exploração da PDAD 2024

Este projeto é um sistema em Python com interface gráfica tkinter para explorar dados da PDAD 2024. O recorte escolhido foi renda e desigualdade no Distrito Federal. O sistema permite filtrar os dados por Região Administrativa, visualizar gráficos e consultar estatísticas descritivas. Também é possível exportar os resultados filtrados para um arquivo CSV.

## Como executar

python sistema.py

## Dependências

pip install pandas matplotlib openpyxl

## Arquivos necessários

- PDAD_2024-Moradores.csv
- PDAD_2024-Domicilios.xlsx
- Dicionario_de_variaveis_PDAD_2024.xlsx

Os arquivos completos devem ser baixados no site da PDAD: https://pdad.ipe.df.gov.br
